## Implementation discipline

Apply [deliverable-driven simplicity](../../agentic-pipelines/references/deliverable_driven_simplicity.md). Use concrete data, ordinary functions and explicit composition first. Introduce a narrow interface only for a demonstrated external/test boundary or a shared contract proved by another slice; an API does not require an interface per method or type. Clock/ID injection may be functions rather than a new port hierarchy. Keep small duplication when sharing would couple independent behavior.

SQLite owns durable truth; one application instance owns backend operations; the GUI owns presentation and gesture state. Notifications only suggest re-querying. Derived state has an explicit lifetime and invalidation rule. Each actual blocking operation may justify bounded asynchronous work; document its owner, outstanding-work limit, ordering, stale-result rejection and shutdown. No generic event bus, service locator, plugin framework, worker pool, retry subsystem, speculative cache or second build engine.
